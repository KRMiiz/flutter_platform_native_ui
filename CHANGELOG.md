## 0.0.1

- Initial release.
- Add `NativeTabBar`, backed by a real UIKit `UITabBar` on iOS 15 and later.
- Support SF Symbols, PNG app/package assets, selected icons, badges,
  accessibility labels, and incremental state updates.
- Add customizable colors and label/badge typography.
- Add `canSelect` for host-controlled selection eligibility.
- Add a minimal iOS example using SF Symbols.
